## jamditis/claude-skills-journalism — lanes 1 + 8

**Claim:** Claude Code skills built for journalism, media and academia — verification,
FOIA, data journalism, academic writing.

**Installed:** `journalism-core@claude-skills-journalism` v1.5.0, user scope, via
`claude plugin marketplace add jamditis/claude-skills-journalism` and
`claude plugin install`. The README says to use the interactive `/plugin` slash command;
the `claude plugin` CLI does the same job non-interactively, which matters if you ever
want this reproducible.

**What it actually grants.** This was the thing worth checking before installing, given
the standing rule that unused agent installs with account access are a liability:

```
Skills (15)  Agents (0)  Hooks (0)  MCP servers (0)  LSP servers (0)
Always-on:   ~881 tok added to every session
```

Zero hooks, zero MCP servers, zero agents. It reads no credentials and opens no network
connections. The wider repo *does* ship hooks — 18 of them — but they belong to other
plugins in the same marketplace and none are installed. The only executable among them,
`pdf-playground/hooks/session-start.sh`, is a 24-hour-cached version check that GETs a
public `raw.githubusercontent.com` URL, sends no payload, and exits silently on failure.
Benign, and it isn't installed anyway.

**Real-material test.** Ran the `data-journalism` skill's validation gates against the
FDA recall analysis from the datasette install below, rather than against a sample.

**Where it broke — in my favour.** The gate "test sensitivity to reasonable definitions
and exclusions" caught a real error in an analysis I had already written down as
finished. My first pass matched Nebraska in the FDA `distribution_pattern` free text with
`LIKE '% NE %' OR LIKE '%,NE,%'`. That misses `"... MO, NE, NH ..."`, because after `NE`
comes a comma, not a space. A token-aware match found **948 more** rows — 1,292 rather
than 344 — and moved the headline from 136× to 203×, a 49% swing from one definition
choice.

That is the whole value of the pack in one example. The skills are checklists, and the
checklist caught something.

**Weaker parts.** `ai-writing-detox` is a banned-word table (delve, realm, tapestry) —
fine, but it duplicates judgement already applied by hand. `fact-check-workflow` overlaps
the existing `research-fact-checker` skill, which is *more* specific: it re-fetches
PubMed abstracts and checks statistics against them, where this one is generic. Two
skills that fire on the same trigger and give different advice is a real cost, not a
neutral.

## simonw/datasette — lane 9

**Claim:** publishes any dataset as an explorable, queryable website. `sqlite-utils` is
the companion for getting data into shape.

**Installed:** datasette 0.65.3, sqlite-utils 4.2.1, via pip. No system dependencies, no
config. Working directory `~/datasette-lane9`.

**Real material:** openFDA food enforcement — every US food recall with a report date
from 2020 onward. 10,161 records, pulled from the public API, loaded with one command:

```
sqlite-utils insert recalls.db recalls recalls.json --pk recall_number --alter
```

**The finding.** The `state` field on an FDA recall is the recalling firm's headquarters,
not where the food went. Distribution lives in `distribution_pattern`, which is free
text — 2,561 distinct values across 10,161 records, never blank.

```
firm HQ in Nebraska                    14
distribution names Nebraska         1,292
distributed nationwide              1,557
------------------------------------------
reached Nebraska (union)            2,842      203x the headquarters count
```

Any "recalls by state" map built on the `state` field — which is the obvious thing to
build, and what the field name invites — understates Nebraska's exposure by more than two
orders of magnitude. The same trap is in every state: nationwide alone is 15% of all
recalls.

**Where it broke.** Two places.

1. openFDA returns **HTTP 404, not an empty result set**, when `skip` passes the end of
   the matched records. A naive paginate-until-empty loop crashes on the last page and
   loses everything already fetched. Cost me the first 3,887 records.
2. The naive `LIKE` match described above. Caught by the journalism-core gates, not by
   datasette.

**What datasette itself did well.** The web UI, ad-hoc SQL over HTTP, a JSON API and CSV
export all came free from one command against a database that did not exist an hour
earlier. `/recalls.csv?sql=...` returning a filtered extract with no export step is the
part that changes how a story gets reported.

## remotion-dev/remotion — lanes 1 + 10

**Claim:** video from React components, so a video becomes a build artifact a pipeline can
regenerate when the data changes.

**Installed:** remotion + `@remotion/cli` 4.0.521, react 19.2. `npm install` was 249
packages in 10s; the first render pulls a 93 MB headless shell.

**Real material:** the live `docs/data/index.json` from this repo — the actual 2026-09-06
weekly run — rendered as a 1080×1350 social card video. Not the template.

```
RadarWeekly   30fps   1080x1350   330 frames (11.00 sec)
render: 6.7s wall clock, 1.3 MB mp4
```

**The claim held.** Regenerating from changed data is a one-line command, and the video is
genuinely a build artifact.

**Where it broke — twice, and the second one matters beyond Remotion.**

1. `<Sequence>` wraps its children in an `AbsoluteFill` unless you pass `layout="none"`.
   Without it every card covers the full frame, so the header and all previous cards
   vanish and you get one card floating at the top. It renders "successfully" and looks
   wrong, which is the worst failure mode for an artifact a pipeline produces unattended.

2. Pointing the same composition at the **2026-09-02** run crashed at frame 1:
   `TypeError: Cannot read properties of undefined (reading 'found')`. That run record has
   no `stats` block at all, and its picks have no `english` or `english_readme` keys. The
   run records in `docs/data/index.json` are **not schema-stable**, and the file keeps a
   52-run window, so any consumer will eventually meet an older shape. Filed separately.

   Credit where due: it failed loudly at frame 1 rather than rendering a wrong video.
   For an unattended build step that is the right behaviour.
